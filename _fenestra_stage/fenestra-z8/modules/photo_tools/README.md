# Photo tools 插件（Z8 C3.11）

此插件控制 camera.photo.tools/v1。需要集成固定上游 a21fc8c04b6dd863439c4192d387b755633287f6 原生照片后端的 Fenestra feature-suite 核心；现有 full-dev7-resume3 核心不包含该服务。旧核心加载插件会显示“Feature-suite core required”。更换桌面工作台不能提供相机原生照片后端。

将 photo-tools.wlm 放入卡的 FENESTRA/ 后由模块管理加载。插件是独立、可重定位的标准 WLM，不把固定地址补丁代码当作可加载模块。原生后端、任务、文件系统和编码代码属于核心，插件退出时不会卸载仍被原厂任务引用的代码。

## RAW 预拍

使用相机原生照片菜单：FX/DX、L、C15/C30，然后选择普通“画质”和“RAW 记录”。HE/HE★ 可用；选择“无损压缩”实际回退 HE★。C60/C120、真正无损预拍、HLG/HEIF 和副卡独立 JPEG 尺寸不在支持范围。插件显示入口说明和当前 RAW 记录值。

写入失败或超时可能生成 Z8PRESTP.BIN；保留两卡文件。上游停止文件机制继续有效。原始照片菜单仍可直接使用；禁用 WLM 不移除核心内的原生预拍钩子。

## 像素位移

原生照片菜单可浏览和选择任意组。插件提供“最新未合成组／全部未合成组”两个批处理入口，打开“Confirm merge”后才启用“Start merge”。它调用同一个永久原生工作线程，不另开相机连接。开始请求先进入 GUI 队列，原厂 GUI 线程确认没有其他照片任务、原生浏览页或合成页占用后才投递，原生任务忙时返回 Busy。

支持完整 4/8/16/32 张、FX/L、8256×5504、14-bit 无损压缩 NEF 组，任意起始文件编号和跨文件夹组沿用上游修复。HE/HE★、DX、残缺、重复帧和 RAW 预拍输出不适用。输出由原生后端以新的 _MERGED.NEFX 或带序号文件名写入，原片及已有输出保留。4/8 张组输出 8256×5504，16/32 张组输出 16512×11008。

“Cancel merge”请求原生工作线程取消；等待写入与关闭完成后才能卸载模块或完成核心停止。断开 GUI 前的停止请求也会直接原子设置当前序列的原生取消位。原厂文件句柄、任务块和线程栈的生命周期沿用原生后端，仍运行时保留核心和 owner。

## 验证范围

tests.test_photo_tools 编译并执行真实服务、原生桥和真实 WLM 状态机的合成测试：GUI 投递、序列唯一 claim、迟到线程撤销、互斥、取消、停止期间延迟 detach、恢复时保留序列、旧核心提示及过期菜单事件拒绝。原生 C 源通过 AArch64 严格警告交叉编译，WLM 通过标准包校验。

运行区偏移由固定上游原始 ps8.c 交叉编译导出；不可用于其他上游版本或其他固件。上述是代码、ABI 和合成传输证据，本次没有拍摄或 NEFX 输出的实机验收，不能称为整机资格验证。
